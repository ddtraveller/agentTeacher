# Kru Eng — Seed Wiki

This directory is the starter knowledge base for **Kru Eng** (ครูอิงค์), an AI tutor that teaches English alongside technology and AI literacy. It's the corpus that bootstraps `khoj`, gets enriched by `hermes-night`, and gets controlled by `owner-bridge`.

## What this is for

The bot doesn't ship with school-specific knowledge baked into its weights. It learns about the school by reading this wiki via Khoj. So whatever you want Kru Eng to know — your curriculum, your students, your pedagogical philosophy, your house style — lives here as markdown.

## How content flows

```
seed_wiki/  (you write this, in git)
    │
    │  docker compose cp ./seed_wiki/. orchestrator:/data/wiki/
    │  -- OR --
    │  bind-mount via docker-compose.override.yml
    ▼
/data/wiki/  (named volume, read-write across services)
    │
    ├──► khoj (read-only)         — indexes every status:live file
    ├──► orchestrator (read-only) — Khoj-mediated retrieval per chat
    ├──► owner-bridge (read-write) — promotes DRAFT, queues night jobs
    └──► hermes-night (read-write) — prunes stale, drafts new lessons, runs STORM
```

## What's here

- **INDEX.md** — schema map. Read this first.
- **school/** — who Kru Eng is, what she teaches, how she teaches.
- **staff/** — the bot's persona prompt (one file; this is the system prompt).
- **students/** — one file per real learner. Start by copying `learner_profile_template.md`.
- **curriculum/** — the twelve-week scope.
- **lessons/** — one file per week, all following `LESSON_TEMPLATE.md`.
- **vocabulary/**, **pronunciation/**, **grammar/** — language resources Kru Eng cites when teaching.
- **assessment/** — how Kru Eng checks understanding.
- **references/** — methodology and operational recipes.

## How to extend

1. Add a new student: copy `students/learner_profile_template.md` → `students/lek.md`, fill it in, set `status: live`.
2. Add a new lesson: copy `lessons/LESSON_TEMPLATE.md` → `lessons/w13_<topic>.md`. Status starts as DRAFT.
3. DM the bot on LINE/Slack: `approve_draft lessons/w13_<topic>.md` to promote.
4. Force a reindex: DM `reindex_khoj` (or wait for the night pass).

## What this is **not**

- **Not a static site.** Don't write HTML in here. Khoj indexes markdown; HTML adds noise.
- **Not a personal journal.** Don't put unscoped reflections in lessons. Use `staff/kru_eng_persona.md` for voice and `assessment/` for technique. Lessons are reproducible artefacts.
- **Not where media lives.** Audio overviews and slide decks generated by NotebookLM go to `s3://krueng.ai/audio/` and are referenced from lessons, not stored here.

## Why markdown and not a CMS

Markdown survives. The bot is local and offline-first. A CMS would need its own database, its own backup story, and its own auth model. Plain text in git already has all three, for free.

## Working language

The wiki is written in **English** because that's the easiest language for the bot to ingest correctly. Where a Thai gloss adds clarity (a vocab item, a cultural concept, a learner's actual L1 utterance), put it inline in parentheses with the Thai script: `market (ตลาด)`. Don't translate full sentences — the bot does that on output.
